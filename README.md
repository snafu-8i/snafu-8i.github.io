# Portfolio de Yves NGUYEN

Bienvenue sur mon **portfolio en ligne** !  
Ce site présente mon **parcours professionnel**, mes **projets personnels** et des informations sur moi-même.

---

## 🌐 À propos du site

Le portfolio est structuré en plusieurs sections :

1. **À propos de moi**  
   Une présentation de mon parcours, de mes compétences et de mes centres d’intérêt.

2. **Parcours professionnel**  
   Mes expériences professionnelles, stages et réalisations dans le cadre de mon travail ou de mes études.

3. **Projets**  
   Une sélection de projets personnels ou professionnels, avec descriptions, technologies utilisées et liens vers le code ou les démos.

4. **Contact**  
   Un formulaire ou mes coordonnées pour me joindre facilement.
